# Sprint Analysis Submission Package

This package follows the original week-by-week folder structure. All current papers, summaries, figures, code, and result files use the same 2,602-sprint analysis.

Folders:
- `guides` - learning and reproduction guides
- `week-08-proposal` - research proposal
- `week-10-baseline-artifact-plan` - baseline checkpoint and working repository snapshot
- `week-12-method-preliminary-results` - reproducible project used for the final analyses
- `week-14-full-results-analysis` - full interpretation of the final results
- `week-16-article-artifact-presentation` - 6-page conference paper, figures, and presentation

For reproduction, start with `REPRODUCE.docx`, then work inside `week-12-method-preliminary-results/sprint-risk-prediction`.

Freeze note: originality reports and extended-draft folders are not included in this cleaned package.
